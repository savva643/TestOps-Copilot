# GigaChat Integration

## Обзор

GigaChat — это AI-помощник для QA-разработчиков, интегрированный в TestOps Copilot. Он помогает генерировать тесты, анализировать код и создавать документацию.

## Модель

Используется модель **GigaChat3-10B-A1.8B** от Cloud.ru:
- **Контекст**: 262,000 токенов
- **Стоимость**: Бесплатно
- **Возможности**: Function Calling, Structured Output

## Архитектура

### Backend (core-agent-service)

GigaChat интегрирован в микросервисную архитектуру:

- **Сервис**: `app/services/gigachat_service.py`
- **Эндпоинты**: `app/api/v1/endpoints/gigachat.py`
- **Роутер**: `/api/v1/gigachat`

### Frontend

- **API клиент**: `frontend/dashboard/src/api/gigachat.ts`
- **UI компонент**: `frontend/dashboard/src/pages/GigachatPage.tsx`

## API Endpoints

### POST `/api/v1/gigachat/chat`

Отправка сообщения в GigaChat.

**Заголовки:**
- `X-API-Key`: API ключ TestOps Copilot (обязательно)
- `X-LLM-API-Key`: API ключ GigaChat от Cloud.ru (обязательно)

**Тело запроса:**
```json
{
  "messages": [
    {"role": "user", "content": "Создай API-тест для эндпоинта /login"}
  ],
  "temperature": 0.5,
  "max_tokens": 4000,
  "session_id": "chat_1234567890_abc123",
  "owner_id": "user_key_id"
}
```

**Параметры:**
- `session_id` (опционально): ID сессии для сохранения в БД
- `owner_id` (опционально): ID пользователя для привязки сессии

**Ответ:**
```json
{
  "content": "Ответ от GigaChat...",
  "model": "GigaChat/GigaChat3-10B-A1.8B",
  "usage": {
    "prompt_tokens": 150,
    "completion_tokens": 200,
    "total_tokens": 350
  },
  "context_tokens": 5000,
  "context_full": false,
  "context_percentage": 1.9
}
```

**Параметры:**
- `messages`: Список сообщений (история разговора)
- `temperature`: Температура генерации (0.0-2.0, по умолчанию 0.5)
- `max_tokens`: Максимальное количество токенов в ответе (1-8000, по умолчанию 4000)

### GET `/api/v1/gigachat/context-info`

Получение информации о лимитах контекста.

**Ответ:**
```json
{
  "max_context_tokens": 262000,
  "recommended_max_request_tokens": 258000,
  "warning_threshold_percentage": 90,
  "model": "GigaChat/GigaChat3-10B-A1.8B",
  "description": "GigaChat3 model with 262k token context window"
}
```

### POST `/api/v1/gigachat/chat/{session_id}/compress`

Сжатие истории чата для сессии.

**Заголовки:**
- `X-API-Key`: API ключ TestOps Copilot (обязательно)
- `X-LLM-API-Key`: API ключ GigaChat (обязательно)

**Ответ:**
```json
{
  "session_id": "chat_1234567890_abc123",
  "compressed_context": "Вопрос: Создай API-тест...\nРешение: Вот готовый тест...",
  "compressed_at": "2024-01-15T10:30:00",
  "original_messages": 25
}
```

### GET `/api/v1/gigachat/chat/{session_id}/memory`

Получение сжатой памяти (контекста) для сессии.

**Ответ:**
```json
{
  "session_id": "chat_1234567890_abc123",
  "compressed_context": "Вопрос: Создай API-тест...\nРешение: Вот готовый тест...",
  "compressed_at": "2024-01-15T10:30:00",
  "total_messages": 25,
  "total_tokens": 5000
}
```

## Управление контекстом

### Ограничения

- **Максимальный контекст**: 262,000 токенов
- **Резерв для ответа**: 4,000 токенов
- **Максимальный запрос**: 258,000 токенов
- **Предупреждение**: при 90% заполнения

### Автоматическая обрезка

Если контекст переполнен, система автоматически:
1. Сохраняет системный промпт
2. Сохраняет последнее сообщение пользователя
3. Обрезает старые сообщения, начиная с самых ранних

### Сохранение и сжатие контекста

Система автоматически сохраняет все сообщения в базу данных:
- **Модель**: `ChatSession` - хранит метаданные сессии
- **Модель**: `ChatMessage` - хранит отдельные сообщения
- **Автосжатие**: При переполнении контекста (>90%) автоматически запускается сжатие

#### Сжатие контекста

Сжатие выполняется с помощью GigaChat AI:
- **Цель**: Сохранить только важную информацию (вопросы и решения)
- **Формат**: "Вопрос: [краткий вопрос] - Решение: [ключевое решение]"
- **Автоматически**: При переполнении контекста
- **Вручную**: Через API `/api/v1/gigachat/chat/{session_id}/compress`

#### Просмотр памяти

Пользователь может посмотреть сжатую память GigaChat:
- **UI**: Меню (три точки) → "Показать память GigaChat"
- **API**: `GET /api/v1/gigachat/chat/{session_id}/memory`

### UI индикаторы

- **Progress bar**: показывает процент заполнения контекста
- **Цветовая индикация**:
  - Зеленый: < 80%
  - Желтый: 80-90%
  - Красный: > 90% (контекст переполнен)

### Блокировка отправки

При переполнении контекста (>90%):
- Отправка сообщений блокируется
- Показывается предупреждение
- Предлагается кнопка "Очистить чат"

## Системный промпт

GigaChat настроен как специализированный помощник для QA:

```
Ты — специализированный помощник для QA-разработчиков в сервисе автоматической генерации тестов.

ТВОЯ РОЛЬ:
1. Помогать создавать тесты трёх типов:
   - РУЧНЫЕ ТЕСТЫ: подробное описание шагов в формате Markdown
   - API-ТЕСТЫ: код на Python с использованием библиотеки requests
   - UI-ТЕСТЫ: код на Python с использованием selenium/playwright

2. Ты получаешь:
   - Исходный код приложения
   - Описание функциональности или требования
   - Файлы проекта для анализа
   - Конкретный запрос пользователя

3. Ты анализируешь материалы и генерируешь:
   - Чистый, готовый к запуску код на Python
   - Документацию в формате Markdown
   - Примеры использования
   - Обработку ошибок
```

## Настройка

### Получение API ключа

1. Зарегистрируйтесь на [Cloud.ru](https://cloud.ru)
2. Создайте проект в разделе Evolution
3. Создайте сервисный аккаунт с ролью "Администратор проекта"
4. Сгенерируйте API-ключ с доступом к Foundation Models
5. Сохраните ключ (после закрытия окна он не доступен повторно)

### Добавление ключа в систему

1. Войдите в TestOps Copilot
2. Перейдите в профиль
3. Введите GigaChat API ключ
4. Ключ сохраняется в `localStorage` как `copilot_llm_api_key`

## Обработка ошибок

### Типичные ошибки

1. **401 Unauthorized**: Неверный API ключ GigaChat
2. **429 Too Many Requests**: Превышен лимит запросов (10 запросов/минуту)
3. **500 Internal Server Error**: Ошибка сервера GigaChat

### Retry логика

- Максимум 3 попытки
- Exponential backoff (1s, 2s, 4s)
- Не повторяются клиентские ошибки (4xx), кроме 429

## Rate Limiting

- **Лимит**: 10 запросов в минуту на API ключ
- **Алгоритм**: Token bucket
- **Ожидание**: Автоматическое при превышении лимита

## Swagger документация

Полная Swagger документация доступна по адресу:
- **Локально**: `http://localhost:8001/docs`
- **Production**: `https://your-domain.com/api/v1/docs`

Эндпоинты GigaChat находятся в разделе `gigachat`.

## Безопасность

- API ключ GigaChat передается через заголовок `X-LLM-API-Key`
- Ключ не сохраняется на бэкенде, передается с каждым запросом
- Все запросы требуют валидный `X-API-Key` (TestOps Copilot API ключ)

## Мониторинг

Логирование выполняется через `structlog`:
- Все запросы логируются
- Ошибки логируются с деталями
- Метрики использования токенов

## Разработка

### Локальный запуск

1. Убедитесь, что `core-agent-service` запущен
2. Установите зависимости фронтенда: `npm install`
3. Запустите фронтенд: `npm run dev`
4. Откройте `http://localhost:3000/gigachat`

```bash
cd backend/core_agent_service
pytest tests/

# Frontend тесты
cd frontend/dashboard
npm test
```
