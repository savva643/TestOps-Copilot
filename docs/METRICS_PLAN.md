# План сбора метрик (фаза 5)

## Что меряем
- Время генерации пачки 5–10 кейсов (цель: <30 сек).
- % тестов, требующих минимальных правок (цель: >80%).
- Покрытие кода автотестов (из GitLab pipelines, cobertura).
- Успех задач: SUCCESS/(SUCCESS+FAILED) — уже показывается на Dashboard.
- Средняя длительность задач — уже показывается на Dashboard.

## Как собирать
- UI/Tasks: фиксировать timestamps создано/обновлено для задач генерации.
- GitLab: в `gitlab-test` включён артефакт coverage.xml; собирать badge.
- Сохранить замеры в `docs/metrics/metrics.json` (формат произвольный: дата, сценарий, значения).

## Формат metrics.json (пример)
```json
[
  {
    "date": "2025-01-15",
    "scenario": "ui-calculator-10-cases",
    "duration_sec": 24,
    "correctness_pct": 86,
    "notes": "UI калькулятор, 10 кейсов"
  }
]
```

## Дальше
- Добавить выгрузку метрик в CI job и визуализацию в Dashboard (график времени генерации).
- Автоалерты: если длительность >30 сек или correctness <80%.
