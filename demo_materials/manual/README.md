# Ручная демо-сессия

> 📖 Вернуться к [главной документации](../../README.md)

Цель: показать генерацию и анализ тест-кейсов без CI/CD.

Что подготовлено:
- `ui-calculator-openapi.yaml` — упрощённая OpenAPI-подобная спецификация UI калькулятора Cloud.ru (страницы: главная, каталог, конфигурация Compute).
- Используйте её для генерации 25–35 ручных тест-кейсов (UI/UX) и сравнения с рекомендациями валидатора.

Сценарий:
1. Откройте экран Generate (UI) и загрузите `ui-calculator-openapi.yaml`.
2. Запустите генерацию ручных тестов (тип: UI, язык: ru, паттерн AAA).
3. В отчёте покажите:
   - число сгенерированных кейсов,
   - заполненные поля (steps, expected, priority, owner),
   - результаты `test-standard-validator` (пропуски/предупреждения).
4. Скачайте ZIP-артефакт и откройте пример теста.

Метрики для замера:
- Время генерации пачки 5–10 кейсов (<30 сек).
- Доля кода/шагов без правок (>80%).
