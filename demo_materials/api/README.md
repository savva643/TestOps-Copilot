# API демо (Evolution Compute)

> 📖 Вернуться к [главной документации](../../README.md)

Цель: показать генерацию 25–35 тест-кейсов (ручные + автотесты) по реальной спецификации API.

Что подготовлено:
- `evolution-compute-sample.yaml` — укороченная спецификация VMs/Disks/Flavors (GET/POST/DELETE).
- Подходит для генерации: API функциональные тесты, контрактные тесты, негативные кейсы.

Сценарий:
1. Загрузите `evolution-compute-sample.yaml` через экран Generate (тип: API).
2. Сгенерируйте набор ручных и автоматизированных тестов (pytest + allure).
3. Покажите валидатор: наличие owner/priority/AAA, привязка меток.
4. Скачайте ZIP-артефакт и откройте 1–2 теста с декораторами allure.
