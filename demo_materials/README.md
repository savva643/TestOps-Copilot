# Демо-материалы TestOps Copilot

Эта папка содержит готовые материалы для быстрой демонстрации:
- `manual/` — ручная генерация/просмотр тест-кейсов по заранее подготовленным спецификациям.
- `api/` — примеры API-спецификаций для генерации автотестов.
- `gitlab/` — сценарий демонстрации интеграции с GitLab (пайплайн, покрытие, артефакты).

Как использовать:
1) Выберите сценарий (ручной/UI, API, GitLab).
2) Загрузите соответствующий файл спецификации или клонируйте тестовый репозиторий.
3) Запустите генерацию/анализ через UI или API TestOps Copilot.
4) Для GitLab — запустите пайплайн и покажите отчёты (coverage, code quality, артефакты).
