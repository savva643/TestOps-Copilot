# Быстрая проверка работоспособности TestOps Copilot

## Шаг 1: Вход в систему

1. Откройте `/login`
2. Заполните форму:
   - **Key ID (IAM)** - ваш Cloud.ru IAM Key ID
   - **Key Secret (IAM)** - ваш Cloud.ru IAM Key Secret  
   - **API Key (Cloud.ru Evolution Model)** - ваш API ключ для модели
3. Нажмите "Войти"
4. После успешного входа вы будете перенаправлены на главную страницу

## Шаг 2: Загрузка OpenAPI спецификации

1. Перейдите на `/generate`
2. Загрузите файл `docs/examples/openapi-evolution-compute-vms.yaml`
3. После загрузки вы должны увидеть список эндпоинтов:
   - `POST /vms` - Создать виртуальную машину
   - `GET /vms` - Получить список VM
   - `GET /vms/{vmId}` - Получить информацию о VM
   - `DELETE /vms/{vmId}` - Удалить VM

## Шаг 3: Генерация тест-кейсов

1. После успешного парсинга нажмите "Сгенерировать тесты"
2. Система создаст задачу генерации
3. Перейдите на `/tasks` для отслеживания прогресса

## Шаг 4: Проверка результата

На странице `/tasks` вы увидите:
- **Статус задачи**: PENDING → PROGRESS → SUCCESS
- **Прогресс**: от 0% до 100%
- **Кнопки**: "Скачать код" и "Скачать артефакты"

## Что проверяется

✅ **Парсер OpenAPI** - извлекает эндпоинты, методы, схемы  
✅ **Формирование промпта** - создает промпт для LLM с паттерном AAA  
✅ **Запрос к LLM** - отправляет запрос в Cloud.ru Evolution Foundation Model  
✅ **Генератор кода** - форматирует и валидирует результат  

## Конвейер работы

```
OpenAPI файл 
  → Парсер (spec-parser-service)
  → Формирование промпта (core-agent-service)
  → Запрос к LLM (Cloud.ru Evolution Model)
  → Генерация кода (code-generator-service)
  → Готовый Python файл с тестами
```

## Пример запроса к LLM

**Промпт для `POST /vms`:**
```
Ты — помощник QA-инженера. Сгенерируй один ручной тест-кейс в формате Allure TestOps as Code (Python) для POST /vms. Используй паттерн AAA (Arrange-Act-Assert). Обязательно добавь декораторы Allure: @allure.title, @allure.feature('VMs'), @allure.story('Create VM'), @allure.label('owner', 'qa-team'). В тесте используй фейковые данные для аутентификации и тестовых данных.
```

**Ожидаемый результат:**
- Python файл с тест-кейсом
- Декораторы Allure (@allure.title, @allure.feature, @allure.story)
- Паттерн AAA (Arrange-Act-Assert)
- Валидный синтаксис Python

## Возможные проблемы

1. **Ошибка 401 при запросе к LLM**
   - Проверьте правильность API ключа модели
   - Убедитесь, что ключ не истек

2. **Ошибка парсинга OpenAPI**
   - Проверьте формат файла (YAML или JSON)
   - Убедитесь, что файл соответствует OpenAPI 3.0

3. **Задача не завершается**
   - Проверьте логи Celery worker
   - Убедитесь, что Redis запущен
