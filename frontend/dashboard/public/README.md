# Статические файлы

Поместите ваши PNG изображения в эту папку:

1. **logo-header.png** - Логотип в углу страницы (в шапке) для светлой темы
2. **logo-header-white.png** - Логотип в углу страницы (в шапке) для темной темы
3. **favicon.png** - Иконка вкладки браузера

## Требования к файлам:

- **logo-header.png**: Рекомендуемая ширина 120px (высота автоматически масштабируется)
- **logo-header-white.png**: Рекомендуемая ширина 120px (высота автоматически масштабируется)
- **favicon.png**: Рекомендуемый размер 32x32px или 16x16px

Все файлы должны быть в формате PNG.
