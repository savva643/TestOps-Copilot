# Статические файлы

Поместите ваши PNG изображения в эту папку:

1. **logo-header.png** - Логотип в углу страницы (в шапке)
2. **favicon.png** - Иконка вкладки браузера

## Требования к файлам:

- **logo-header.png**: Рекомендуемый размер 28x28px или больше (будет масштабирован)
- **favicon.png**: Рекомендуемый размер 32x32px или 16x16px

Оба файла должны быть в формате PNG.
